深度｜POP MART 海外维权全面提速：LABUBU、MOLLY、DIMOO 卖家必须重估风险

张
张兆新 律师 中美双证 · 天册律所
2026-11-26 阅读约 8 分钟 2,486

过去两年，中国出海卖家对美国 TRO（Temporary Restraining Order，临时限制令）的认知，大多停留在"大牌玩具""运动品牌""影视 IP"这几类原告身上。但从稻草人研究部对 TROTracker 监控数据的持续跟踪来看，一个此前被低估的原告阵营正在快速升温——潮玩 IP。

其中最具代表性的，就是 POP MART（泡泡玛特）。随着 LABUBU 在海外社交平台持续破圈、MOLLY 与 DIMOO 形成稳定的全球粉丝盘，泡泡玛特围绕这些核心 IP 的海外维权动作明显加密。对经营潮玩、毛绒挂件、盲盒周边、贴纸钥匙扣等品类的跨境卖家而言，这已经不是一个"要不要关注"的问题，而是一个"什么时候轮到自己"的问题。

核心判断

潮玩 IP 的维权逻辑与传统的商标维权不同：它同时具备版权（角色形象、美术作品）与商标（品牌名、图形商标）两条主张路径，且角色形象的可版权性在美国法下相对容易主张。这意味着卖家即便"没有用 POP MART 的名字"，只要产品外观与角色高度近似，同样可能被纳入 TRO 范围。

一、维权力度为什么在上升：从"品牌出海"到"权利出海"

理解泡泡玛特的维权节奏，需要先理解它的商业结构。潮玩企业的核心资产不是产能，而是 IP。当一个 IP 在海外市场完成冷启动、进入放量阶段，仿品与"擦边款"往往同步涌入——这正是权利方从"容忍"转向"清场"的时间窗口。

据稻草人分析，潮玩类 IP 在海外维权通常呈现三个递进阶段：

  • 第一阶段：平台投诉为主。通过电商平台的知识产权投诉通道下架链接，成本低、见效快，但不触及资金。
  • 第二阶段：海关与边境保护备案。对批量进口的仿品进行扣留，切断供应链端。
  • 第三阶段：联邦法院 TRO / 初步禁令。直接冻结收款账户，形成对卖家的实质性压力，并以此推动和解。

从 TROTracker 的监控趋势看，泡泡玛特相关 IP 的动作正在向第三阶段靠拢。这类案件的典型特征是：立案节奏集中、被告名单长、冻结范围覆盖多个平台店铺，且原告方通常委托在美国联邦法院有成熟 TRO 操作经验的律所代理。

高危品类提示

以下品类在潮玩 IP 维权中属于高暴露面：毛绒挂件与玩偶、盲盒及"同款"盒装产品、亚克力钥匙扣与冰箱贴、手机壳与贴纸、服饰印花（尤其角色脸部特写）。即便产品图做了"改色""换表情""加配件"处理，只要整体视觉识别度指向特定角色，仍存在被认定侵权的风险。

二、涉及律所与典型打法：为什么"没收到通知"也会被冻结

在美国联邦法院的 TRO 实践中，潮玩类原告方通常采用"密封起诉 + 单方申请"的模式：起诉状与被告名单在初期处于密封状态，卖家在账户被冻结前往往毫不知情。这也是大量卖家在旺季突然发现回款中断、店铺无法提现的根本原因。

从稻草人代理 500+ TRO 案件的经验看，此类案件的常见打法包括：

  1. 以版权主张为主、商标为辅。角色形象作为美术作品主张版权，绕开"卖家是否使用了品牌名"的争议。
  2. 批量被告合并起诉。将多个平台的数十甚至上百个店铺列入同一案件，摊薄单案成本，同时放大威慑。
  3. 快速申请初步禁令。在 TRO 到期前推动 PI（Preliminary Injunction），使冻结状态延续，压缩卖家的谈判空间。
  4. 以"和解"为主要变现路径。多数案件最终以和解结案，和解金通常与冻结金额、销售量、侵权情节挂钩。

需要强调的是，不同原告、不同律所、不同法院的处理节奏差异很大。卖家如果套用其他案件的经验去预判本案时间线，很容易错过应诉或谈判的最佳窗口。

三、卖家最容易踩的三个认知误区

误区一："我卖的是自己设计的，不算侵权"

"自己设计"在法律上并不等于"不侵权"。版权侵权的判断标准是实质性相似（substantial similarity），而非是否复制了原文件。对潮玩角色而言，标志性的耳朵形状、牙齿、配色比例、面部轮廓，都可能构成受保护的表达元素。

误区二："账户里钱不多，不值得处理"

冻结只是开始。若案件推进到缺席判决（Default Judgment），可能产生远高于账户余额的判赔金额，并在未来影响同一主体在美国市场的收款通道与平台入驻。据稻草人分析，早期介入的处置成本通常显著低于判决后的被动局面。

误区三："等原告联系我再说"

在密封起诉模式下，原告没有义务在冻结前通知你。等到你发现时，TRO 的答辩窗口可能已经过去大半。时间本身就是这个游戏里最贵的成本。

可立即执行的三件事

1）盘点在售 SKU 中所有含角色形象的商品，尤其是"无品牌名但有角色脸"的款式；
2）保留采购合同、供应商授权文件、设计稿与上架时间记录，这些是后续主张善意使用或压低和解金的关键证据；
3）对高风险链接做下架与库存隔离处理，避免在案件推进期间产生新的销售记录。

四、稻草人观察：潮玩维权将成为下一阶段的高频赛道

从 TROTracker 的品类分布看，潮玩与二次元周边类案件的占比在持续上升。这一趋势背后有两个结构性原因：一是中国 IP 出海进入收获期，权利方有动力也有预算做全球维权；二是美国联邦法院对 TRO 程序的接受度高，维权成本相对可控。

对卖家而言，这意味着"潮玩周边"不再是一个可以靠信息差获利的品类。选品阶段的知识产权筛查，正在从"加分项"变成"准入项"。

给卖家的策略建议

把 IP 风险前置到选品环节：建立"角色形象 — 商标 — 版权"三维筛查清单；对拿不准的款式，宁可放弃也不要用"改一改"的方式试探。已经卷入案件的卖家，则应尽快完成案件核对与时间线梳理，再决定应诉、和解还是弃店。

潮玩 IP 的维权，本质上是一场关于"识别度"的博弈。你越像它，风险越高；你以为的"差一点"，在法官眼里可能正是"刚刚好"。

在 TRO 这件事上，最贵的从来不是律师费，而是你以为还有时间。
