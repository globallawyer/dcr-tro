深度预警：POP MART 北美维权全面提速，LABUBU 卖家正在被重点盯上

张
张兆新 律师 中美双证 · 天册律所
2026-09-27 阅读约 7 分钟 3,812

过去两年，泡泡玛特（POP MART）从一家中国潮玩公司，变成了北美电商平台上被高频提及的"维权原告"。据稻草人研究部 TROTracker 监控数据，涉及 POP MART 相关 IP 的 TRO（临时限制令）申请在近一年内呈现明显上升趋势，被告店铺覆盖亚马逊、eBay、TikTok Shop、独立站等多个渠道，其中相当一部分是中国卖家。

这不是一次偶发的批量投诉，而是一套已经成型的、以商标为核心、辅以版权与外观设计的组合维权策略。对于仍在销售 LABUBU、MOLLY、DIMOO 相关产品的卖家来说，理解这套策略的运作方式，比事后找律师解冻更重要。

先记住三个关键词

POP MART 的维权不是"只打假货"，而是围绕 商标（Trademark）+ 版权（Copyright）+ 外观设计 三条线同时展开。很多卖家以为自己卖的是"正品代购"或"自制周边"就能免责，实际上踩中的往往是商标与版权，而非真假问题。

一、维权主体与 IP 矩阵：不止 LABUBU 一个雷区

泡泡玛特在海外的知识产权布局，通常通过其关联主体与授权主体分别持有商标与版权。卖家最容易误判的一点，是把注意力全部集中在 LABUBU 上。事实上，据稻草人分析，其维权覆盖的 IP 至少包括以下几个层级：

  • 核心爆款 IP：LABUBU（THE MONSTERS 系列）、MOLLY、DIMOO、SKULLPANDA、HIRONO 等，这些是维权火力最集中的对象；
  • 文字与图形商标："POP MART""LABUBU""MOLLY"等文字商标，以及角色形象图形商标，均在多类别注册；
  • 版权层面：角色美术作品、包装设计、宣传图等，构成独立的版权主张基础；
  • 外观与包装：盲盒盒型、系列包装、特定配色组合，也可能被纳入主张范围。

这意味着，即便你的 Listing 标题里没有写"LABUBU"，只要主图、A+ 页面或变体图里出现了角色形象，依然可能被取证。

二、维权路径与取证逻辑：为什么"我只是代购"也不安全

从稻草人代理和观察的案件看，POP MART 一方在美维权的典型路径是：先由调查方在平台进行隐蔽取证（下单购买、截图固定 Listing 与页面），再由美国本地律所向法院提交 TRO 申请，法院批准后由平台执行账户冻结。整个过程卖家往往在冻结发生后才知情。

这里必须纠正一个高频误区：

"我卖的是正品，为什么也被冻结？"

商标权用尽（First Sale Doctrine）在理论上有适用空间，但实践中卖家极难自证货源合法链路，且平台层面通常先执行冻结、后由卖家举证。更关键的是，很多卖家使用的 Listing 图片、文案本身来自官方或网络，这部分版权与商标使用问题与商品真假无关，照样构成主张基础。此外，未经授权使用品牌名做关键词引流，也可能被单独主张。

另据稻草人分析，盲盒类产品的"拆盒""改娃""二次创作"周边，是当前被取证的高发品类。这类产品在卖家视角是"原创手工"，在权利人视角则可能同时触及角色版权与商标。

三、高风险行为清单：这几类卖家请立刻自查

结合 TROTracker 的监控维度与稻草人经手案件，以下行为属于当前 POP MART 相关维权的高风险区，建议逐条自查：

  1. Listing 主图或详情页直接使用官方角色图——无论商品是否正品，图片版权风险独立存在；
  2. 标题/关键词堆砌 IP 名称——如"for LABUBU""MOLLY style"，即便加了 for，也可能被主张混淆；
  3. 销售自制改娃、贴纸、手机壳、服饰等衍生品——角色形象版权 + 商标双重风险；
  4. 盲盒代购、拆盒转卖——货源链路不清时，商标权用尽抗辩难以成立；
  5. 独立站与社媒引流——TikTok、Instagram 上的推广内容同样会被取证。

一个实用的自查动作

把你的店铺当作"原告律师"来审一遍：假设你要起诉这家店，你会截图哪几张图、引用哪几个词？凡是你能想到的，对方基本也能想到。这一步做完，很多风险点会立刻浮现。

四、收到冻结后，正确的处理顺序

很多卖家在收到平台通知后的第一反应是慌，第二反应是删链接。据稻草人经验，这个顺序恰恰是反的。正确的处理逻辑大致是：

  • 第一步：固定证据。保存平台通知、冻结金额、被诉 Listing 截图，避免后续举证被动；
  • 第二步：确认原告与主张范围。是商标、版权还是外观设计，直接影响应对策略与谈判空间；
  • 第三步：评估店铺价值。冻结金额、店铺权重、后续经营计划，决定是和解、应诉还是放弃；
  • 第四步：由专业律师介入沟通。自行联系原告律所，往往因表述不当而抬高对方预期。

需要强调的是，TRO 案件的走向高度个案化，涉及冻结金额、原告策略、法院态度等多重变量，任何"包解冻""保证低和解金"的承诺都不可信。据稻草人分析，越早介入、证据越完整，谈判空间通常越大。

IP 维权正在从"打假"走向"打使用"。对跨境卖家而言，真正的护城河不是货源，而是对商标、版权边界的清醒认知。

POP MART 的这轮维权，本质上是潮玩 IP 全球化过程中的必然动作。它不会只针对某几个卖家，而是会持续筛选整个生态。与其等冻结通知，不如现在就把 Listing 里那些"看起来没问题"的图片和关键词，重新审一遍。
