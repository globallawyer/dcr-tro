深度预警｜POP MART 海外维权全面提速，LABUBU / MOLLY / DIMOO 卖家该警惕什么？

张
张兆新 律师 中美双证 · 天册律所
2026-10-27 阅读约 8 分钟 1,842

过去两年，POP MART（泡泡玛特）完成了从"潮玩品牌"到"全球化 IP 运营方"的身份切换。LABUBU 在北美与欧洲的爆红，让这个原本偏亚洲市场的品牌，在海外电商渠道获得了前所未有的曝光——同时也把大量跨境卖家推到了它的维权雷达上。

据稻草人研究部对 TROTracker 监控数据的持续跟踪，POP MART 系 IP 相关的维权动作在过去一段时间内呈现明显的节奏加快、权利基础多元化、打击对象前移三个特征。这不是一次偶发的维权，而是一套正在成型的系统性策略。本文尝试从卖家视角，把这套策略拆开来看。

先记住三个关键词

权利基础多元化（商标 + 版权 + 外观设计）、维权主体关联化（品牌方与授权运营方交替出手）、打击对象前移（从大卖家向中小卖家与铺货型店铺延伸）。理解这三点，比记住任何一个案号都重要。

一、维权力度：从"选择性出手"到"常态化监控"

早期 POP MART 在海外的维权，更多集中在少数头部侵权主体，属于典型的"选择性出手"。但随着 LABUBU 相关产品在亚马逊、Temu、TikTok Shop、独立站等渠道的铺货量激增，这种策略已经难以覆盖实际侵权规模。

据稻草人分析，其维权模式正在向"常态化监控 + 批量取证 + 阶段性集中立案"演进。这意味着两件事：

  • 取证周期被拉长。品牌方或其委托的调查机构可能提前数月对目标店铺进行截图、下单、公证取证，卖家在收到 TRO 时，往往侵权证据链已经相当完整。
  • 立案呈现"批次化"。同一批案件可能在同一法院、相近时间集中提起，被告名单动辄数十家店铺，这与稻草人处理过的大量批量 TRO 案件特征高度一致。

对卖家而言，最危险的不是"被起诉"，而是"被起诉时才发现自己早就被盯上了"。

二、涉及律所：品牌方通常如何组织维权力量

关于具体承办律所，稻草人研究部倾向于提醒卖家关注律所类型而非纠结于具体名称。从公开维权路径与行业惯例看，POP MART 这类全球化 IP 运营方的海外维权，通常由以下几类主体协同完成：

  1. 美国本土知识产权诉讼律所。负责在特定联邦法院提起 TRO / 初步禁令程序，熟悉当地法官对潮玩类 IP 的裁判倾向。
  2. 品牌保护与调查机构。负责线上巡查、侵权线索筛查与证据固定，是"批量取证"的实际执行方。
  3. 本地化授权代理。在部分市场通过授权运营主体出面主张权利，形成"品牌方 + 运营方"交替出手的格局。

卖家实用提示

收到 TRO 后，第一时间核对起诉状中的原告主体与代理律师信息，判断这是品牌方直接起诉，还是授权运营方或调查机构推动的案件。这直接影响后续沟通路径与谈判节奏。

三、典型案件特征：潮玩类 IP 的三个"高危区"

结合稻草人处理过的同类潮玩与动漫 IP 案件经验，POP MART 系 IP 的维权通常围绕三个高危区展开，卖家可对照自查：

1. 商标层面：名称与图形商标的双重覆盖

LABUBU、MOLLY、DIMOO 等名称在多个类目下均有商标布局，且往往同时覆盖文字商标与图形商标。卖家在标题、五点描述、A+ 页面中直接使用这些名称，即便产品本身并非仿品，也可能构成商标性使用。

2. 版权层面：角色形象与衍生设计

潮玩 IP 的核心价值在于角色形象。产品图案、包装、周边（贴纸、钥匙扣、服饰印花）只要实质性相似，就可能落入版权主张范围。这一层面的认定门槛，往往比卖家预期的低。

3. 外观设计层面：造型与配件的近似

部分市场对立体造型可主张外观设计或类似权利。玩偶本体、配件、展示盒的造型近似，是潮玩类案件中被频繁援引的权利基础。

常见误区：只改名字就安全？

大量卖家以为"不写 LABUBU 就没事"。实际上，若产品造型、图案与官方角色构成实质性相似，即便标题完全规避名称，仍可能被版权或外观设计主张命中。规避名称不等于规避风险。

四、卖家现在该做什么

预警的价值不在于制造焦虑，而在于把动作提前。据稻草人分析，面对 POP MART 系 IP 的维权提速，卖家可以从三个层面着手：

  • 立即自查。对在售与历史下架链接做一次全面筛查，重点看标题、图片、A+ 内容与产品造型，而非仅看关键词。
  • 留存证据。对已下架产品、供应商授权文件、进货凭证做好归档，这些在后续沟通中可能直接影响处理结果。
  • 建立监控。关注同品类、同渠道的 TRO 动态，提前感知批次化立案的节奏，避免被动应诉。

一个务实的判断

并非所有涉及潮玩元素的店铺都会被起诉。真正决定风险高低的，是侵权特征的明显程度与经营规模。越早完成自查与调整，越能把主动权握在自己手里。

POP MART 的海外维权，本质上是一个成熟 IP 运营方在全球化过程中必然要走的一步。对卖家来说，这不是"要不要面对"的问题，而是"什么时候面对、以什么姿态面对"的问题。

潮玩 IP 的红利期，和它的维权期，往往是同一段时间。看得懂趋势的人提前收手，看不懂的人替别人交学费。

稻草人研究部将持续通过 TROTracker 跟踪 POP MART 系 IP 的维权动态。如果你正在销售相关品类，或已经收到相关通知，建议尽早做一次专业评估——在 TRO 这件事上，时间从来不是中立变量。
