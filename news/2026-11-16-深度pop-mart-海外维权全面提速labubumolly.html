深度｜POP MART 海外维权全面提速：LABUBU、MOLLY、DIMOO 卖家该如何自查

张
张兆新 律师 中美双证 · 天册律所
2026-11-16 阅读约 8 分钟 3,182

过去两年，泡泡玛特（POP MART）从"潮玩公司"变成了"全球 IP 运营商"。LABUBU 在欧美社交平台持续破圈，MOLLY 与 DIMOO 的联名款在二级市场溢价明显。热度之外，另一条线索同样值得跨境卖家警惕：POP MART 的海外知识产权维权动作，正在从"零散投诉"转向"系统性执法"。

据稻草人研究部对 TROTracker 监控数据的持续跟踪，涉及 POP MART 系 IP 的维权投诉与诉讼线索，近两年在北美市场的出现频次明显上升，且呈现出"多 IP 打包、多平台同步、节奏密集"的特征。对做潮玩、盲盒、周边、贴纸、钥匙扣、毛绒挂件的卖家而言，这已经不是"要不要关注"的问题，而是"什么时候轮到我"的问题。

一、维权路径：商标与版权"双线并行"，版权才是真正的杀伤力

很多卖家对 POP MART 的认知还停留在"注册商标"层面，认为只要不直接使用 "POP MART" 字样就安全。这是一个典型误判。

从稻草人代理与观察到的案件结构看，POP MART 系 IP 的维权通常同时铺设两条线：

  • 商标线：包括 "POP MART" 文字商标、品牌 Logo，以及部分 IP 名称本身的文字商标。这条线相对容易识别，卖家规避意识也较强。
  • 版权线：这才是核心。LABUBU 的尖牙兔形象、MOLLY 的湖蓝大眼女孩形象、DIMOO 的云朵头男孩形象，作为美术作品（artwork）在多个法域享有版权保护。卖家即便不使用任何品牌文字，只要商品图案、造型、包装视觉与这些角色构成实质性相似，就可能落入版权侵权范围。

关键要点：改色、改名、改比例，都不等于"改掉侵权"

版权侵权的判定核心是"实质性相似"，而非"完全一致"。把 LABUBU 换成粉色、把 MOLLY 的眼睛改成棕色、把 DIMOO 的云朵头改成尖角头，只要整体视觉特征仍可被识别为同一角色，抗辩空间都非常有限。稻草人在 500+ 案件复盘中反复看到，卖家最常见的错误就是"以为改一改就没事"。

此外，POP MART 在海外多采用"版权 + 商标 + 外观设计"的组合主张，并在部分案件中配合平台投诉（如亚马逊的 IP 投诉通道、eBay 的 VeRO 机制）先行下架，再视情况推进诉讼。这意味着卖家的风险窗口远早于收到法院传票——链接被批量下架、账户资金被冻结，往往才是第一信号。

二、涉及律所与受理法院：为什么卖家总在"意想不到的地方"被起诉

据稻草人分析，POP MART 在北美维权时，倾向于委托具备跨境电商批量诉讼经验的美国本地律所，并选择对权利人相对友好的联邦地区法院立案。这类法院的共同特点是：立案门槛低、可申请单方（ex parte）临时限制令、审理节奏快。

这对卖家的直接影响是：

  1. 你可能完全不知情。TRO 通常在被告缺席的情况下签发，平台收到法院命令后直接冻结账户，卖家往往在提现失败时才发现问题。
  2. 应答窗口极短。临时限制令之后通常紧接初步禁令（Preliminary Injunction）程序，留给卖家组织抗辩、联系律师、评估和解的时间非常有限。
  3. 多被告合并起诉。权利人常把数十甚至上百个店铺打包在同一案件中起诉，卖家即便"只卖了几件"，也可能被列入名单。

高风险信号：出现以下情况请立即自查

① 商品标题或图片中出现 LABUBU、MOLLY、DIMOO、THE MONSTERS 等关键词；② 售卖"同款""平替""盲盒散货""隐藏款"潮玩周边；③ 使用与官方高度相似的包装、吊牌或展示图；④ 近期收到平台 IP 投诉通知但未处理。以上任一情形，均建议在账户被冻结前完成排查。

三、卖家最容易踩的三个坑

坑一：把"潮玩周边"当成"通用品类"

钥匙扣、手机壳、贴纸、抱枕、毛绒挂件、桌面摆件——这些品类本身没有问题，问题在于上面印了什么。稻草人接触的案例中，大量卖家并非主营潮玩，而是在铺货时顺手上了几款"热门形象"周边，结果成为被告。铺货越杂，越需要逐条排查。

坑二：依赖供应商的"授权承诺"

部分供应商会口头或书面声称"有授权""可以卖"，但授权链条是否真实、是否覆盖你销售的平台与地区、是否覆盖你实际使用的图案，往往经不起推敲。一旦进入诉讼，供应商的承诺不能替你免责，卖家仍需自行承担应诉与和解成本。

坑三：收到冻结后拖延观望

这是最致命的。TRO 冻结后，账户资金、库存、店铺权重都在持续受损，而法律程序的时钟不会暂停。据稻草人分析，越早介入的案件，卖家在和解谈判中的主动权越大；拖延到缺席判决阶段，可操作空间会被大幅压缩。

实用建议：建立"IP 黑名单 + 定期巡检"机制

把 LABUBU、MOLLY、DIMOO、THE MONSTERS、SKULLPANDA、CRYBABY 等已知 IP 列入内部黑名单，在新品上架前做一次关键词与图片双重比对；对存量链接每月巡检一次。成本极低，但能挡掉大部分"无心之失"。

四、写在最后：热度越高，越要敬畏 IP

POP MART 的海外维权不是偶发动作，而是其全球化 IP 战略的必然组成部分。当一个 IP 的二级市场溢价足够高，权利人就一定有动力去清理"搭便车"的供给。对跨境卖家来说，这不是"运气问题"，而是可预判、可管理、可规避的经营风险。

真正安全的做法从来不是"等被冻结了再找律师"，而是在选品阶段就把 IP 风险纳入决策。潮玩赛道的钱可以赚，但赚的前提是——你卖的东西，经得起一封律师函的审视。

热度是别人的，账户是自己的。在 IP 维权越来越"工业化"的今天，合规不是成本，而是你留在牌桌上的资格。
