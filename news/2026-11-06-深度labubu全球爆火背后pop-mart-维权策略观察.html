深度｜LABUBU全球爆火背后：POP MART 维权策略观察

张
张兆新 律师 中美双证 · 天册律所
2026-11-06 阅读约 7 分钟 3,182

过去两年，泡泡玛特（POP MART）完成了从"潮玩公司"到"全球 IP 运营商"的身份切换。LABUBU 在欧美社交平台被明星带火之后，MOLLY、DIMOO、SKULLPANDA 等经典 IP 的海外授权与衍生品需求同步放大——与此同时，围绕这些形象产生的仿品、未经授权的周边、二次创作商品，也在亚马逊、Temu、TikTok Shop、独立站等渠道快速铺开。

据稻草人研究部对 TROTracker 监控数据的持续跟踪，POP MART 系 IP 在海外的维权动作，已经从"零星发函"进入"批量立案 + 平台投诉并行"的阶段。对跨境卖家而言，这不是一个"潮玩圈的事"，而是一条正在收紧的合规红线。

一句话结论

POP MART 的维权不是单点打击，而是"商标 + 版权 + 外观设计"三线并进、平台投诉与联邦诉讼双轨并行。卖家只要在标题、图片、包装、模具任一环节踩线，都可能被纳入同一批次的取证范围。

一、维权主体与 IP 矩阵：不是"一个泡泡玛特"在打

很多卖家误以为"权利人只有一个泡泡玛特"，实际上海外维权通常由多层主体发起：

  • IP 持有与运营主体：负责商标与著作权登记，是绝大多数诉讼与平台投诉的名义原告；
  • 区域子公司 / 授权代理：在目标市场（尤其美国、欧洲）持有本地商标或独家授权，便于在当地法院取得管辖权；
  • 艺术家与设计方：LABUBU 由艺术家龙家升（Kasing Lung）创作，相关著作权链条与泡泡玛特的商业授权相互交织，实践中常出现"著作权人 + 商业运营方"共同主张的情形。

这种多层结构带来的直接后果是：卖家很难通过"我只用了图形没用文字"或"我只卖了配件没卖整只"来规避。不同主体可以就不同权利基础分别主张，取证范围也更宽。

从 IP 矩阵看，目前海外维权活跃度较高的包括 LABUBU（The Monsters 系列）、MOLLY、DIMOO、SKULLPANDA、CRYBABY 等。据稻草人分析，LABUBU 因全球热度最高，是当前仿品密度与维权密度"双高"的品类。

二、涉及律所与典型案件形态

从稻草人代理与观察到的案件分布看，POP MART 系 IP 的海外维权呈现出几个鲜明特征：

1. 代理律所：以美西知识产权诉讼律所为主

美国市场的维权通常由长期深耕伊利诺伊州北区法院（N.D. Ill.）等"TRO 友好型"法院的知识产权律所代理。这类律所的操作模式高度标准化：批量取证 → 单案多被告（Schedule A）→ 申请临时 restraining order（TRO）→ 冻结收款账户 → 以和解为主要出口。

2. 案件类型：商标为主，版权与外观设计为辅

与纯版权案件不同，POP MART 系案件往往以商标侵权为第一主张（品牌名、系列名、Logo），再叠加著作权侵权（角色形象、包装插画）与外观设计（部分市场有注册设计）。这意味着即使卖家把标题里的品牌词删干净，只要商品图仍是可识别的角色形象，风险依然存在。

高风险信号：这些做法正在被批量取证

① 商品主图直接使用官方角色图或"同款"渲染图；② 标题/五点描述含 LABUBU、MOLLY、DIMOO 等词；③ 销售"适配 LABUBU 的衣服/配件"并在文案中明示；④ 盲盒形式的"仿系列"包装；⑤ 独立站使用角色形象做引流素材。以上任一项，都可能成为同一批次取证的依据。

3. 平台投诉与诉讼并行

值得注意的是，POP MART 并非只走法院。平台端的商标/版权投诉（Amazon Brand Registry、Temu 知识产权投诉通道等）响应更快、成本更低，往往是诉讼前的"第一轮清扫"。据稻草人分析，不少卖家是先收到平台下架与账户审核通知，随后才在 TROTracker 上看到对应的联邦案件。

三、对跨境卖家的实际影响：三个容易误判的点

误判一："我没卖假货，只是风格相似。" 著作权保护的是"表达"，角色形象的脸型、耳朵、配色、比例组合一旦构成实质性相似，即便你自己开模，也可能被认定侵权。风格（style）本身不受保护，但具体角色表达受保护——这条线比很多卖家想象的要细。

误判二："我在国内生产，美国法院管不到我。" 只要商品通过亚马逊 FBA、第三方海外仓或独立站进入美国市场，且收款账户、平台店铺与美国有连接点，美国法院对被告行使管辖权并冻结相关资金在实践中并不罕见。

误判三："下架了就没事了。" 下架只解决平台层面，诉讼层面的索赔与和解谈判是另一条线。账户冻结若未及时处理，资金滞留时间越长，谈判筹码越弱。

实操建议：三步自查

① 词表自查：把 LABUBU、THE MONSTERS、MOLLY、DIMOO、SKULLPANDA、CRYBABY 及其中英文变体加入标题/搜索词黑名单；② 图片自查：清理所有含可识别角色形象的 listing 图、A+ 素材、独立站 banner；③ 供应链自查：向工厂确认模具来源与授权链条，保留书面记录，以备日后抗辩"善意使用"或降低主观恶意认定。

四、趋势判断：维权会更快、更批量、更跨平台

结合 TROTracker 的监控节奏与稻草人代理经验，我们对 POP MART 系 IP 的维权走向有三个判断：

  1. 立案节奏加快：热门 IP 的维权窗口期正在缩短，从"发现仿品"到"批量立案"的间隔预计进一步压缩；
  2. 被告范围外扩：从整只仿品延伸到配件、服装、贴纸、家居衍生品等"边缘品类"，卖家不能只盯"是不是卖娃娃"；
  3. 跨平台联动：亚马逊、Temu、TikTok Shop、独立站支付通道可能被同时主张，单一平台下架不再等于风险解除。

对卖家来说，最理性的策略不是"赌自己没被盯上"，而是把 IP 合规前置到选品与上架环节。潮玩 IP 的衍生需求是真实存在的，但"蹭热度"和"侵权"之间只隔着一层授权。

热度是别人的，账户是你的。在 IP 维权越来越标准化的今天，合规不是成本，而是留在牌桌上的门票。
