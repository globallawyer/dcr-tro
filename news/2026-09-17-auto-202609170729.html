深度预警：POP MART 海外维权全面提速，LABUBU 卖家正在成为头号目标

张
张兆新 律师 中美双证 · 天册律所
2026-09-17 阅读约 8 分钟 3,842

过去两年，跨境圈对 TRO 的注意力主要集中在卡通形象、运动品牌和奢侈品类目。但从稻草人 TROTracker 监控数据看，一个此前被低估的维权主体正在快速上升——POP MART（泡泡玛特）及其海外授权体系。

LABUBU 的全球爆红，让这个原本属于"潮玩圈"的 IP 一夜之间成为跨境卖家的流量密码。毛绒挂件、盲盒、钥匙扣、手机壳、贴纸、亚克力立牌……大量卖家涌入，随之而来的是维权方的全面反击。据稻草人分析，2025 年下半年以来，与 POP MART 相关 IP 的投诉、平台下架和 TRO 申请数量均呈明显上升趋势。

这不是"蹭热度"的问题，而是资产冻结的问题

很多卖家以为卖几个毛绒玩具"没人管"。实际上，一旦原告在美国法院拿到 TRO，PayPal、亚马逊店铺余额、第三方收款账户都可能在数小时内被冻结。维权方的目标从来不是单个链接，而是账户里的全部资金。

一、维权主体：不止是 POP MART 一家

理解 POP MART 的维权策略，首先要搞清楚"谁在告"。从稻草人经手的案件和监控记录看，围绕这些 IP 的维权主体至少包括三层：

  • POP MART 本体及其海外子公司：直接持有 LABUBU、MOLLY、DIMOO、SKULLPANDA、HIRONO 等核心 IP 的商标与著作权，是发起维权的主力。
  • 签约艺术家与设计工作室：LABUBU 由艺术家龙家升（Kasing Lung）创作，相关著作权链条往往涉及艺术家本人及其授权实体，维权时可能出现"双主体"甚至"多主体"并行主张。
  • 海外授权与被授权方：部分品类（如联名服饰、文具、食品）通过授权合作落地，被授权方在特定品类内也具备独立维权资格。

这意味着，卖家面对的可能不是一封投诉信，而是多主体、多权利基础（商标 + 版权 + 外观设计）的叠加主张。抗辩空间因此被大幅压缩。

二、涉及律所与案件特征：从"零星投诉"到"批量起诉"

从我们观察到的趋势看，POP MART 在海外维权上正从早期的平台投诉，转向更系统化的美国联邦法院诉讼路径。这通常意味着：

  1. 原告代理律所趋于专业化：多由熟悉 Schedule A 类案件（即针对大量匿名被告的批量诉讼）的律所操作，流程高度标准化。
  2. 被告名单批量列示：一次起诉可能涉及数十甚至上百个店铺，卖家往往在账户被冻结后才知道自己"上榜"。
  3. 取证以截图和购买测试为主：原告通常通过平台页面截图、下单取证固定侵权证据，链条清晰、举证成本低。

关键判断

潮玩 IP 的维权门槛，比传统卡通形象更低。原因在于：LABUBU、MOLLY 等形象具有高度可识别的独创性表达，著作权主张几乎不需要额外证明"知名度"，商标注册也相对完备。卖家"改个颜色、换个姿势"的做法，基本无法规避侵权认定。

三、高风险品类与卖家的常见误区

根据稻草人 500+ 案件的经验，以下几类商品是当前 POP MART 相关维权的高发区：

品类 风险等级 常见侵权基础
毛绒玩具 / 挂件 极高 著作权 + 商标
盲盒 / 手办 极高 著作权 + 外观设计
手机壳 / 贴纸 / 亚克力 高 著作权 + 商标
服饰印花 / 帆布包 高 著作权 + 商标
文具 / 家居周边 中高 商标为主

卖家最常见的三个误区：

  • "我只是代购正品"：未经授权使用 IP 形象做商品图、标题关键词，同样构成侵权，与商品真伪无关。
  • "我改了造型就不算"：只要整体视觉形象与受保护作品构成实质性相似，改动细节不构成抗辩。
  • "等被冻结再说"：TRO 一旦生效，资金冻结期间的损失往往远超和解成本，越晚介入越被动。

四、卖家现在应该做什么

预警的价值在于"提前"，而不是"事后"。给跨境卖家三条可立即执行的建议：

可执行清单

1）立即下架所有未经授权使用 LABUBU、MOLLY、DIMOO 等形象的 listing，包括标题、主图、A+ 页面中的形象元素；
2）排查供应链——很多卖家并非自己设计，而是"供应商给的图"，风险同样由卖家承担；
3）若账户已被冻结，第一时间固定证据、核对原告主张，切勿自行联系对方或盲目承认侵权。

需要特别提醒的是：POP MART 的维权节奏与 LABUBU 的热度高度相关。热度越高，维权投入越大。据稻草人分析，未来一段时间内，围绕该 IP 体系的 TRO 案件数量预计仍将维持高位，且可能向更多周边品类扩散。

在跨境生意里，流量是别人的，账户里的钱才是自己的。当一个 IP 火到"人人都想卖"的时候，往往也是它维权最狠的时候。

潮玩出海是机会，但机会的另一面是合规成本。与其在冻结通知到来时手忙脚乱，不如在选品阶段就把 IP 风险算进成本表。稻草人团队将持续通过 TROTracker 追踪 POP MART 相关案件动态，为卖家提供第一时间的预警与应对支持。
